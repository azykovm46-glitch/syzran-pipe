# Механическое снятие изоляции со стальных труб

Адаптивный прототип сайта услуги в Сызрани и Самарской области. При прокрутке одна труба постепенно освобождается от битума и обёртки. При включённом уменьшении движения оба состояния показаны статично.

## Как открыть

Откройте `dist/index.html` в браузере. Можно также запустить локальный сервер из корня проекта:

```sh
python3 -m http.server 8000 --directory dist
```

Затем перейдите на [localhost:8000](http://localhost:8000). Сборка и установка зависимостей не нужны.

## Файлы

- `dist/index.html` — страница, условия услуги и контакты.
- `dist/style.css` — оформление, адаптивная вёрстка и состояния анимации.
- `dist/script.js` — анимация прокрутки и мобильная кнопка контактов.
- `dist/assets/` — иллюстрации трубы до и после очистки.

## Статус прототипа

Для расчёта посетитель пишет в Telegram, звонит по телефону или переходит в объявление на Авито. Перед публикацией добавьте подтверждённые фото работ. Кадры анимации показывают принцип очистки.


В блоке оборудования есть ссылка на галерею объявления. Чтобы подключить собственную съёмку станка, положите видео и его обложку в `dist/assets/`. Внутри `.machine-media` замените текст со ссылкой на нативный плеер со своими именами файлов. Например:

```html
<video controls playsinline preload="none" poster="assets/station-poster.webp"
       src="assets/station.mp4" aria-label="Механическая очистка трубы на станке"></video>
```
